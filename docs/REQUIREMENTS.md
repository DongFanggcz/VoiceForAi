# 语音输入浮窗 — 需求文档

## 1. 产品概述

语音输入浮窗是一款 Windows 桌面工具，通过语音识别将说话内容转为文字并自动复制到剪贴板，方便用户快速向 AI 助手、聊天框或任意输入框粘贴文字。典型使用场景：说话 → 自动转文字 → 自动复制 → `Ctrl+V` 粘贴。

核心特点是**极简交互**：常态只有一个可拖动的小圆按钮，识别由点击或全局快捷键触发，识别结果自动复制。

## 2. 目标用户

- 经常需要向 AI 助手输入指令的开发者/办公用户
- 需要语音快速记录文字的普通用户
- 对"边说边出文字"有实时性要求的场景

## 3. 运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 64 位 |
| 网络 | 阿里云引擎需联网；本地 vosk 引擎离线可用 |
| 麦克风 | 任意可用麦克风（内置/外接均可） |
| 运行时 | Node.js ≥ 22.12（开发）；打包后无需 |

## 4. 功能需求

### 4.1 双引擎识别

| 引擎 | 说明 | 网络 | 准确率 | 实时性 |
|------|------|------|--------|--------|
| 阿里云 NLS（在线，默认） | 阿里云智能语音交互实时流式识别 | 需要 | 高 | 边说边出 |
| 本地 vosk（离线） | vosk-browser WASM 本地识别 | 不需要 | 中 | 分段出 |

- 用户可在设置面板切换引擎，选择自动记忆（`localStorage`）

### 4.2 极简交互

- **常态**：仅显示一个 48px 圆形麦克风按钮，可拖动、可点击
- **点击按钮**：开始识别；识别中再点击 → 停止（启动/结束同键）
- **悬停按钮 2 秒**：展开完整设置面板；鼠标移开面板后收起
- **长按按钮 0.3 秒**：出现扩散光环特效
- **全局快捷键**：任何程序内触发开始/停止识别（默认 `Ctrl+Shift+V`，可自定义）

### 4.3 识别与结果处理

- 识别过程中文本实时显示在面板文字区（中间结果灰色、最终结果白色）
- **识别结束自动复制**完整文本到剪贴板（无需手动复制）
- 静音超过 4 秒自动停止识别并复制

### 4.4 设置项

| 设置 | 说明 |
|------|------|
| 快捷键 | 点击后按下新组合键自定义（如 `Alt+C`、`Alt+X`、`F1` 等），自动保存 |
| 透明度 | 滑块 40%~100% 调节窗口透明度 |
| 置顶 | 是否始终置顶显示 |
| 引擎 | 阿里云（在线）/ 本地 vosk（离线） |
| 语言 | 普通话 / 繁体中文 / English / 日本語 / 한국어 |

### 4.5 窗口管理

- 无边框透明小窗，始终置顶（可关）
- 位置可拖动，展开面板可缩放
- 关闭按钮退出；最小化按钮收起

## 5. 非功能需求

- **隐私**：阿里云模式将音频发送至阿里云服务；vosk 模式音频不出本机
- **配置安全**：阿里云 AccessKey/Appkey 存于 `config.json`（git 忽略），不在代码中硬编码
- **可移植性**：打包为独立 EXE，免安装即可运行；桌面快捷方式一键直达

## 6. 技术架构

```
┌─────────────────────────────────────────────┐
│  渲染进程 (renderer.js)                     │
│  - 麦克风采集 (getUserMedia)                │
│  - 交互逻辑 (点击/悬停/长按/拖动)           │
│  - vosk 本地识别 (WASM)                     │
└──────────────┬──────────────────────────────┘
               │ IPC (contextIsolation + preload)
┌──────────────▼──────────────────────────────┐
│  主进程 (main.js)                           │
│  - 窗口管理 / 全局快捷键                     │
│  - 本地 HTTP 服务 (静态资源 + 模型)          │
│  - NLS 客户端 (nls.js) 流式识别              │
└──────────────┬──────────────────────────────┘
               │ WebSocket
┌──────────────▼──────────────────────────────┐
│  阿里云 NLS 智能语音交互 (在线)              │
└─────────────────────────────────────────────┘
```

## 8. 后续优化方向（规划）

| 方向 | 说明 | 优先级 |
|------|------|--------|
| 代码签名 | 购买代码签名证书，避免 Smart App Control 拦截 | 高 |
| 配置引导 | 首次运行无凭证时，在界面引导填写并保存到 userData | 高 |
| 更大 Whisper 模型 | 本地离线引擎换 whisper-small/medium，提升离线准确率 | 中 |
| 语音活动实时可视化 | 录音时显示波形/音量条 | 中 |
| 双击快捷输入 | 识别后自动模拟粘贴到当前输入框（需剪贴板注入） | 中 |
| 开机自启 | 加入开机自动启动选项 | 低 |
| 多语言模型热切换 | vosk/whisper 多语言模型按需下载 | 低 |
| 界面主题 | 深色/浅色/自定义主题色 | 低 |
