# 测试文档

本文档包含**测试程序说明**（如何自测各功能）与**完整测试用例**（验收标准），供后续开发与打包验证使用。

## 1. 测试环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 64 位 |
| 麦克风 | 可用（内置/外接） |
| 网络 | 测试阿里云引擎需联网；测试 vosk 离线引擎可断网 |
| 依赖 | 已 `npm install`，已配置 `config.json` |

## 2. 测试程序说明

### 2.1 手动测试入口

```bash
cd voice-desktop
npm start
```

### 2.2 自动化脚本（scripts/）

| 脚本 | 用途 | 用法 |
|------|------|------|
| `nls-test.js` | 用 wav 文件验证阿里云 NLS 识别链路（Token 获取 + WebSocket + 流式） | `node scripts/nls-test.js <16k.wav>` |
| `nls-module-test.js` | 验证主进程 nls.js 模块（重采样 + 流式识别） | `node scripts/nls-module-test.js <任意.wav>` |
| `e2e-test.js` | 端到端：模拟 48kHz 麦克风输入 → 重采样 → NLS 识别 | `node scripts/e2e-test.js <wav> [48000]` |

> 自动化脚本直接调用主进程模块，不依赖 GUI，适合回归验证识别链路。

## 3. 功能测试用例

### TC-01 启动与窗口

| 步骤 | 预期 |
|------|------|
| 运行 `npm start` | 出现 64×64 透明小窗，仅一个蓝色圆按钮，无黑框 |
| 拖动圆按钮 | 窗口随鼠标移动，松开定位 |
| 长按按钮 0.3 秒 | 出现扩散光环特效，松开消失 |

### TC-02 展开/收起面板

| 步骤 | 预期 |
|------|------|
| 悬停圆按钮 2 秒 | 窗口展开为 300×420 完整面板 |
| 鼠标移开面板 | 约 1.2 秒后自动收起回小按钮 |
| 点击按钮（不悬停） | 只触发识别，不展开面板 |

### TC-03 录音与识别（阿里云引擎）

| 步骤 | 预期 |
|------|------|
| 点击圆按钮 | 按钮变红、状态显示「正在聆听」 |
| 对麦克风说话（如"你好"） | 状态显示识别中；展开面板可见实时文字 |
| 再次点击按钮（或按快捷键） | 停止识别，状态「已停止」 |
| 粘贴测试 | 剪贴板内容 = 完整识别文本（自动复制） |

### TC-04 静音自动停止

| 步骤 | 预期 |
|------|------|
| 开始识别后静默不说话 | 4 秒后自动停止，复制已识别文本，状态「静音超时，已自动停止」 |

### TC-05 全局快捷键

| 步骤 | 预期 |
|------|------|
| 在其他程序中按 `Ctrl+Shift+V` | 触发开始/停止识别 |

### TC-06 自定义快捷键

| 步骤 | 预期 |
|------|------|
| 展开面板 → ⚙ → 点「快捷键」行 | 显示「按下新快捷键…」 |
| 按下 `Alt+C` | 快捷键更新为 Alt+C，自动保存 |
| 重启应用 | 快捷键仍为 Alt+C |
| 在其他程序按 `Alt+C` | 触发识别 |

### TC-07 离线引擎（vosk）

| 步骤 | 预期 |
|------|------|
| ⚙ → 引擎切到「本地 vosk」 | 加载模型（首次约 10-30 秒） |
| 断网后点击按钮说话 | 仍能识别并复制 |

### TC-08 设置项

| 步骤 | 预期 |
|------|------|
| 调透明度滑块 | 窗口实时变透明/不透明，重启后保持 |
| 关闭「置顶」 | 窗口不再置顶 |
| 切换语言 | 按所选语言识别 |

## 4. 验收标准（打包前）

- [ ] TC-01 至 TC-08 全部通过
- [ ] 录音后剪贴板自动得到完整文本（无缺失）
- [ ] 快捷键可自定义且重启保持
- [ ] 无控制台报错（仅 Electron 安全警告属正常）
- [ ] 打包后 EXE 可直接运行，桌面快捷方式可用

## 5. 打包与分发

### 5.1 打包命令

```bash
cd voice-desktop
npx electron-builder --win nsis
```

### 5.2 产物

- 安装包：`dist/语音输入浮窗 Setup x.x.x.exe`
- 安装后自动创建**桌面快捷方式**（安装时勾选「创建桌面快捷方式」）
- 双击桌面快捷方式即可启动

### 5.3 打包注意事项

- 首次打包会下载 electron 二进制，网络慢时配置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`
- 模型文件（`model.tar.gz`、`models/`）较大，未打包进安装包；离线引擎需用户自行放置
- `config.json`（含密钥）不打包，首次运行需用户自行配置
